# Datheon Python Programming Internship

This repository contains three Python projects completed as part of the Datheon Python Programming Internship.

## Projects

### Task 1: Hangman Game
A command-line word-guessing game where users guess letters to reveal a hidden word.

**Features**
- Random word selection
- Limited incorrect guesses
- Input validation
- Duplicate-guess handling
- Win and loss conditions

**Run**
```bash
python task1_hangman/main.py
```

### Task 3: Automated File Organizer
A Python utility that organizes files into folders based on their extensions.

**Features**
- Categorizes common file types
- Previews planned file movements
- Requests confirmation before moving files
- Handles duplicate filenames
- Reports errors and completed movements

**Run**
```bash
python task3_file_organizer/main.py
```

### Task 4: Rule-Based FAQ Chatbot
A command-line chatbot that answers predefined questions using keyword matching.

**Features**
- FAQ responses for multiple topics
- Case-insensitive input handling
- Keyword matching and response prioritization
- Greeting and exit commands
- Fallback response for unknown questions

**Run**
```bash
python task4_faq_chatbot/main.py
```

## Requirements

- Python 3.10 or later recommended
- No third-party packages required
